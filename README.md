# vignette-multiclass-logistic-regression

Our group is planning to create a vignette on logistic regression using the Red Wine Quality dataset to predict whether a wine is of great (score ≥ 6) or good quality (4 <= score < 6) or bad quality (score < 4). We intend to cover data preprocessing, model implementation, performance evaluation, and common pitfalls such as class imbalance, outliers, and multicollinearity.
