# vignette-multinomial-logistic-regression

Our group is planning to create a vignette on multinomial logistic regression using the Red Wine Quality dataset to predict whether a wine is of high quality (score ≥ 7) or medium quality (5 <= score < 7) or low quality (score < 5). We intend to cover data preprocessing, model implementation, performance evaluation, and common pitfalls such as class imbalance, outliers, and multicollinearity.
